# WS2812 全彩灯带控制器（ESP32-C3 + 人体存在联动）

180 颗 WS2812 灯珠、GPIO6 驱动，ESP32-C3 以 **AP + DNS 强制门户**方式提供网页控制台，
并通过 **ESP-NOW** 接收 `hunman_test`（LD2402 人体存在雷达）的广播实现自动亮灭与交互特效。

## 一、硬件连接

| 灯带 / 电源 | ESP32-C3（AirM2M Core） | 说明 |
| --- | --- | --- |
| DIN（数据） | **GPIO6**，串 330 Ω 电阻 | 电阻紧靠 ESP32 端，抑制振铃 |
| +5V | 不要从开发板取电 | 由独立 5V 电源直供灯带 |
| GND | 与开发板 GND **共地** | 必须共地，否则数据不稳定 |

- **电流**：180 颗全白约需 10.8 A。固件默认限流 **3000 mA**（网页可改），FastLED 会自动压低整体
  亮度不超过设定值。请把这个值调到不超过实际电源能力的 80%。
- 在灯带电源入口并联 **1000 µF/10V 以上电解电容**，长距离供电建议两端同时馈电。
- WS2812 在 5V 供电下通常能识别 3.3V 电平；若灯带较长或首颗灯闪烁异常，加一片
  74HCT245 / SN74AHCT125 电平转换。
- 板载 LED 在 GPIO12 / GPIO13，与 GPIO6 无冲突。

## 二、编译与烧录

```bash
pio run            # 编译
pio run -t upload  # 烧录
pio device monitor # 查看串口日志（115200）
```

首次编译会自动安装 FastLED 3.7.8。`scripts/ascii_link_paths.py` 用于解决工程路径含中文时
Windows 链接器读不到 map 文件的问题，请勿删除。

## 三、连接与使用

1. 上电后搜索热点 **`RGB-LED-LAB`**，密码 **`rgb12345`**。
2. 连接成功后手机/电脑通常会**自动弹出控制台**（Android / iOS / Windows 的联网检测都会
   被重定向）。若没弹出，浏览器访问 <http://192.168.4.1>。
3. 网页顶部实时显示：人体在场状态、ESP-NOW 链路、灯带运行状态、渲染帧率，
   下方是**灯带实时预览条**（设备真实像素回传）。

> 热点名称与密码可在网页“预设与系统”里修改，保存后设备自动重启。

| 颜色擦除 | 彗星 | 来回扫描 | 流星雨 |
| 弹跳球 | 五彩纸屑 | 星光闪烁 | 闪耀微光 |
| 雪花飘落 | 火焰 | 烛光 | 闪电 |
| 频闪 | 警灯 | 心跳 | 律动节拍 |
| 交错光点 | 等离子 | 柏林噪声 | 极光 |
| 海洋波涛 | 涟漪 | 烟花 | 正弦游走 |
| 双色追逐 | 糖果条纹 | 星河 | **距离雷达** |
| **存在热度** | 彩虹呼吸 | 数字雨 | 双波混合 |
| 彩虹Pride | 激光扫射 | 瀑布流 | 中心爆开 |
| 多层波浪 | 熔岩灯 | 追逐填充 | 仙女灯 |
| 雨滴 | 柔和闪烁 | 光束扫描 | 双色渐变 |
| 呼吸灯条 | **接近光晕** | | |

粗体三个是为人体传感器专门设计的联动效果：
- **距离雷达**：灯带从头部亮到目标距离对应的位置，配合扫描光点，直观显示人离传感器多远。
- **存在热度**：无人时冷蓝，检测到运动转暖橙，静止驻留转青绿，颜色平滑过渡。
- **接近光晕**：人越靠近光晕越大越亮，运动偏暖、静止偏冷。

另支持 **自动轮播**（按间隔切换灯效）、**走近提亮**（距离映射亮度）、**情绪同步**（运动/静止自动切换动感或安静效果）。

16 种调色板（彩虹 / 熔岩 / 海洋 / 极光 / 樱花 …），其中「自定义双色 / 自定义单色」直接
使用网页上选的主副色。

**速度滑条为 0 会定格画面**，可用来把动态效果当静态氛围灯用。

## 五、入场 / 退场特效

14 种揭示动画，与上面 54 种灯效**自由组合**（灯效照常渲染，特效只控制“哪些像素、以多亮
的程度显现”）：

立即、整体淡入、头部扫入、尾部扫入、中心扩散、两端收拢、随机溶解、彗星扫入（带白色彗核）、
交错拉链、闪白淡入、波纹扫入、棋盘展开、两端淡入、像素喷发。

入场 / 退场时长可分别设置（默认 1400 ms / 2200 ms）。

## 六、人体存在联动

| 功能 | 说明 |
| --- | --- |
| 自动感应 | 有人 → 播放入场特效点亮；无人超过“保持时间”→ 播放退场特效 |
| 无人保持 | 0–3600 s，最后一次检测后继续点亮的时间 |
| 无人微亮 | 0 时退场后完全熄灭；>0 时退场停留在该亮度守夜 |
| 动静调速 | 有人运动时动画加速约 1.5 倍，静止驻留时降到 0.65 倍 |
| 距离跟随光斑 | 按上报距离在灯带对应位置叠加一团青白光斑，人走近光斑跟着移动 |
| 到场涟漪 | 人刚被检测到时，从其距离位置向两端扩散一圈白色涟漪（叠加在入场特效之上） |
| 走近提亮 | 人越近整体亮度越高（约 45%～100% 映射） |
| 情绪同步 | 雷达判定运动/静止切换时，自动挑选动感或安静灯效 |
| 自动轮播 | 点亮期间按设定间隔自动切换动画 |
| 雷达量程 | 距离到灯带位置的映射量程，默认 600 cm |

**传感器掉线处理**：超过 3 秒收不到广播时，网页会把 ESP-NOW 徽章标红提示离线；
灯带不会把掉线反向判成“有人”，而是继续按最后一次有人上报和“无人保持”时间退场。

### ESP-NOW 协议

与 `hunman_test` 完全一致，19 字节紧凑结构，信道 **6**（两端必须相同）：

```c
struct __attribute__((packed)) PresencePacket {
  uint32_t magic;       // "PRES" = 0x53455250
  uint8_t  version;     // 1
  uint8_t  presence;    // 0 无人 / 1 有人
  uint8_t  radarResult; // 0 无人 / 1 运动 / 2 静止
  uint8_t  source;      // 1 UART / 2 GPIO 兜底
  uint16_t distanceCm;
  uint32_t sequence;
  uint32_t uptimeMs;
  uint8_t  checksum;    // 前 18 字节异或
};
```

magic、版本、长度、校验和四项全部通过才会被采纳，异常包计入网页的“异常”计数。

## 七、HTTP 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/` | 控制台页面 |
| GET | `/api/meta` | 灯效 / 调色板 / 特效名称列表、灯珠数、引脚、信道、固件版本 |
| GET | `/api/live` | 全部参数 + 传感器状态 + 预览像素（网页每 350 ms 轮询一次） |
| GET | `/api/set?键=值` | 修改参数，可一次传多个 |
| GET | `/api/preset?slot=0..3&do=save\|load` | 4 组预设 |
| GET | `/api/save` | 立即写入 Flash |
| GET | `/api/wifi?ssid=&pass=` | 修改热点并重启 |

`/api/set` 常用键：`pw` 开关、`br` 亮度、`sp` 速度、`in` 强度、`fx` 灯效、`pl` 调色板、
`c1`/`c2` 颜色（6 位十六进制）、`rv` 反向、`mi` 镜像、`sg` 分段、`am` 自动感应、
`hs` 保持秒数、`en`/`ex` 入场/退场特效、`em`/`xm` 特效时长、`ib` 无人微亮、
`mb` 动静调速、`df` 距离光斑、`pg` 到场涟漪、`mr` 雷达量程、`ma` 限流、
`ac` 自动轮播、`cs` 轮播秒数、`ad` 走近提亮、`ms` 情绪同步。

例如命令行直接点亮火焰效果：

```bash
curl "http://192.168.4.1/api/set?fx=17&pl=6&br=180&sp=150"
```

参数改动会在最后一次操作 4 秒后自动写入 NVS，掉电不丢。

## 八、代码结构

```
include/config.h     引脚、灯珠数、信道、ESP-NOW 报文定义
include/state.h      Settings / SensorState 结构与各模块接口
include/web_page.h   控制台单页（HTML/CSS/JS，存放于 PROGMEM）
src/effects.cpp      渲染管线：54 灯效 + 16 调色板 + 14 揭示特效 + 叠加层
src/web.cpp          AP 强制门户、DNS、REST 接口
src/main.cpp         AP 启动、ESP-NOW 接收、人体存在状态机、NVS 持久化
```

渲染管线：

```
灯效 → canvas[虚拟长度] → 分段/镜像/反向展开 → leds[180]
     → 距离光斑叠加 → 入场/退场遮罩 → 到场涟漪叠加 → 亮度 → FastLED.show()
```

动画使用受速度滑条缩放的**虚拟时钟**推进，因此调速不会让画面跳变，速度 0 即定格；
拖尾类效果的衰减按“每虚拟秒”计算，帧率波动不改变观感。

## 九、故障排查

| 现象 | 处理 |
| --- | --- |
| 灯带完全不亮 | 检查共地、5V 供电、GPIO6 接在 DIN（不是 DO） |
| 只有前几颗亮 | 电源电流不足，或限流值设得过低 |
| 颜色顺序不对 | 灯带是 RGB 排列，把 `effects.cpp` 中 `addLeds<WS2812B, LED_PIN, GRB>` 的 `GRB` 改为 `RGB` |
| 偶发闪烁 | 在 `platformio.ini` 的 `build_flags` 加 `-DFASTLED_RMT_BUILTIN_DRIVER=1` 后重新编译 |
| ESP-NOW 一直离线 | 确认雷达端也在信道 6 且已上电；两端 `WIFI_CHANNEL` 必须一致 |
| 网页不自动弹出 | 手机可能关闭了门户检测，手动访问 <http://192.168.4.1> |
| 忘记热点密码 | 用 `pio run -t erase` 清空 NVS 后恢复默认 `RGB-LED-LAB` / `rgb12345` |
